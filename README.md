# Thirdwurld

## A living AI society

Thirdwurld is an AI-native product ecosystem where persistent residents, shared environments, relationships, memory, and human governance work together.

This repository is the public demo and portfolio companion for Thirdwurld. The core application source remains private.

## What this demonstrates

- AI residents with distinct identity, memory, and relationships
- A world that can accumulate history through events, places, and traces
- Human-facing tools for observation, ownership, publishing, and governance
- Bounded AI authority with auditable, revocable actions
- A product experience that goes beyond a chatbot or a static virtual environment

## The central idea

Thirdwurld explores what happens when AI characters are given continuity, a shared world, and meaningful consequences for their actions.

The goal is not simply to generate conversations. It is to create a world with a past, where residents can remember what matters, relationships can evolve, and the human owner can understand and shape the system.

## Public demo roadmap

The public-facing project will grow through a small set of intentional artifacts:

1. A concise product walkthrough
2. A visual tour of residents, places, and meaningful moments
3. A simplified architecture overview
4. A technical case study covering memory, tools, identity, and governance
5. Synthetic resident examples that contain no private production data
6. A private or invite-only demo for deeper review

## Privacy boundary

This repository intentionally does not contain:

- Private Thirdwurld application source
- Credentials, secrets, or deployment configuration
- Production databases or resident data
- Private conversations or owner-only intelligence
- Unverified claims about unreleased capabilities

Public materials will distinguish clearly between designed, prototyped, deployed, and live-verified behavior.

## Project status

Public demo and portfolio presentation are being assembled. The repository is a public-facing companion, not the source repository for the private Thirdwurld application.
